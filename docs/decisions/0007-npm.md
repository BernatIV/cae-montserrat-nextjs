# 0007. npm com a gestor de paquets
- Estat: Acceptada
- Data: 2026-10-26

## Context
npm ve instal·lat amb Node.js, i Vercel i GitHub Actions el suporten sense configuració addicional.

## Decisió
Fer servir npm, amb el `package-lock.json` versionat.

## Conseqüències
- No cal instal·lar cap eina addicional.
- Les instal·lacions són una mica més lentes que amb pnpm, cosa irrellevant per a un projecte d'aquesta mida.

# 0001. Next.js a Vercel en lloc de WordPress

- Estat: Acceptada
- Data: 2026-10-26

## Context

La web actual és un WordPress amb Elementor Pro i té un cost mensual d'allotjament i llicències. Volem cost zero i un manteniment fet amb IA.

## Decisió

Reescriure la web amb Next.js (App Router), TypeScript strict i Tailwind CSS, allotjada a Vercel (pla Hobby) i desplegada automàticament des de GitHub.

## Conseqüències

- Sense costos d'allotjament ni de llicències.
- Web estàtica, ràpida i segura (no hi ha base de dades ni PHP per atacar).
- Cal migrar el contingut i redissenyar.
- El pla Hobby de Vercel és per a ús no comercial. Una coral sense ànim de lucre hi encaixa, però si canvia la situació caldria revisar-ho.
